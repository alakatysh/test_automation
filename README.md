**Варіант:** 11 (Перетворення числа на римський запис для діапазону від 1 до 3999)

---

## Структура проєкту

- `src/roman.ts` — модуль із функцією `convertToRoman(num: number)` для перетворення цілих чисел у римський запис.
- `tests/roman.test.ts` — автоматизовані модульні тести (Vitest) для перевірки коректних, межових та некоректних даних.
- `eslint.config.mjs` — конфігурація статичного аналізатора коду ESLint.
- `.prettierrc` — налаштування автоматичного форматування коду Prettier.
- `.prettierignore` — перелік папок, які ігноруються форматувальником коду.
- `tsconfig.json` — конфігурація компілятора TypeScript та типів.
- `vitest.config.ts` — налаштування тестового раннера Vitest, провайдера покриття V8 та мінімальних порогів (80%/80%/100%).
- `package.json` — описує залежності проєкту (`devDependencies`) та скрипти запуску.
- `.gitignore` — список файлів і папок, що ігноруються системою Git (`node_modules/`, `coverage/`, `dist/`).
- `README.md` — документація проєкту, опис структури та інструкції із запуску.
