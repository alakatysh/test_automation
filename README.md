**Варіант:** 11 (Перетворення числа на римський запис для діапазону від 1 до 3999)

---

## 📁 Структура проєкту

- `src/roman.ts` — модуль із функцією перетворення чисел у римські символи.
- `tests/roman.test.ts` — автоматизовані модульні тести (Vitest).
- `eslint.config.mjs` — конфігурація статичного аналізатора коду ESLint.
- `.prettierrc` — налаштування автоматичного форматування коду Prettier.
- `tsconfig.json` — конфігурація компілятора TypeScript та типів.
- `vitest.config.ts` — налаштування тестового раннера Vitest та порогів покриття.
- `package.json` — описує залежності та скрипти запуску проєкту.
- `.gitignore` — список файлів і папок, які ігноруються системою Git.
